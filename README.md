# Sushi Page

Workspace de estrategia, diseño y desarrollo para una experiencia web de portfolio basada en Ryo Sushi.

## Punto de entrada

1. Lee [`PROJECT.md`](PROJECT.md) para conocer el estado, alcance y próxima decisión.
2. Lee [`AGENTS.md`](AGENTS.md) antes de modificar estructura, documentación, diseño o código.
3. Abre el [entregable creativo HTML](deliverables/design/ryo-unboxed-creative-direction.html) para revisar la dirección visual; [`RealizeDesign.md`](RealizeDesign.md) conserva el índice de decisiones y [`planning-docs/`](planning-docs/) las fuentes especializadas.

La aplicación se incorporará en `website/` cuando la dirección, el contenido y el vertical slice estén definidos. Esta primera etapa prepara el sistema de trabajo; todavía no inicia la implementación.

## Estructura

| Ruta | Responsabilidad |
|---|---|
| `brand/` | Identidad, tokens y assets aprobados del proyecto. |
| `deliverables/` | Entregas visuales y estructurales revisables en HTML. |
| `planning-docs/` | Briefs, inventarios, blueprints, especificaciones y roadmap. |
| `references/` | Material externo de consulta con procedencia documentada. |
| `reports/` | QA, auditorías y evidencia fechada. |
| `.agents/skills/` | Procedimientos reutilizables propios del workspace. |
| `website/` | Aplicación web cuando comience la implementación. |
