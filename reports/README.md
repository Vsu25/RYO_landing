# Reports

Resultados verificables de QA, auditoría y lanzamiento.

## Convención

`YYYY-MM-DD-entregable-version-qa.md`

Cada reporte debe indicar:

1. alcance y versión revisados;
2. entorno, URL o commit;
3. verificaciones ejecutadas;
4. resultado y defectos;
5. evidencia visual o salida de comandos;
6. riesgos residuales;
7. gate aprobado o pendiente.

Las capturas se agrupan en `reports/visuals/<entregable-version>/` y se enlazan desde el reporte.
