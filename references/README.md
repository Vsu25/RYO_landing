# References

Material externo utilizado para estudiar contenido, composición, comportamiento o dirección visual.

Una referencia no tiene autoridad automática sobre el producto y no es un asset de producción por defecto. Cada set debe registrar:

- fuente y URL;
- fecha de consulta;
- autor o negocio;
- propósito de la referencia;
- archivos descargados;
- permiso, licencia o atribución requerida;
- decisiones derivadas.

Los archivos se agrupan por fuente y fecha cuando sea útil: `nombre-fuente-YYYY-MM-DD/`.
