## Antes de incorporar archivos

1. Registra la publicación, historia destacada, menú o enlace en `planning-docs/content-and-source-inventory.md`.
2. Conserva la URL y fecha de consulta.
3. Usa nombres descriptivos: `instagram-post-plato-fecha.ext`, `menu-fecha-pagina-01.ext`.
4. No edites el original; crea derivados únicamente después de seleccionar y autorizar el uso.
5. No guardes cookies, credenciales, exports privados o datos personales.

## Subcarpetas previstas
